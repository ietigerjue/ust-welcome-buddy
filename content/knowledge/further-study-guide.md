## 一、RA申请和套磁

> 来源：MSSS 工科理科TPG毕业找工作攻略——RA篇
> 原文链接：https://mp.weixin.qq.com/s/2I8pKhXoReLmj3MfvaoZww

### 1. 香港就业背景与RA机会

香港产业结构单一，主要为金融及金融相关产业，极大压缩了工科理科相关专业的就业机会。然而，香港拥有大量优质名校资源，香港所有高校实验室都有招RA（Research Assistant，研究助理/实验室助理）的传统。

**RA职位简介：**
- RA是低于Research Associate和Post-Doc Fellow的职位，后者大多只招博士毕业生
- 香港各高校RA薪资 **16000港币起跳**，港科大RA如有香港硕士学历更可达 **2万港币月薪**
- 另有政府要求补贴的 **强积金5%**

### 2. 科大TPG申请RA的优势

相比其他应聘者，科大TPG在RA申请中有独特优势：

**满足香港学历要求**
大部分港府批的科研项目（如ITF）要求项目RA必须有香港学历，而科大TPG恰好满足这一条件。

**竞争压力小**
港校本科生几乎都不会去做RA。本科生科研能力不强，且港校本科生中local同学占九成，他们更偏爱产业界，不愿意做科研（香港人对于科研的兴趣相对较低，读研究生者甚少）。

**科研能力强**
在全港高校中，港科大科研实力最强，很多招RA的港校老板都偏爱港科硕士毕业生。

### 3. RA经历对职业发展的帮助

香港高校的RA offer甚至优于世界五百强公司的研发岗，原因如下：

**更多选择**
香港高校世界排名均在前200，教授背景也非常不错，可为未来发展提供更多选择。

**超高福利与环境优越**
香港大学对科研要求高，对教授管理严，因此很少见压榨学生的情况，实验室气氛比较友好。虽然有科研压力，但工作环境优于大多数公司。

**未来职业发展的定心丸**
RA可以接触前沿科技，在科技变化快速的时代，是未来职业发展的保障。

## 二、博士申请

> 来源：MSSS 在科大读博是一种什么体验？
> 原文链接：https://mp.weixin.qq.com/s/nzuO7GQGRYwoeY8qaJFhzQ

### 1. 基础知识

#### 1.1 PhD之路

- **PhD（Doctor of Philosophy）**：哲学博士，不意味着与"哲学"有关，词源古希腊意为"对智慧的爱"
- 科大的博士学位只有PhD
- 通往PhD的三个阶段：
  1. 注册就读时 → **PhD student/博士生**
  2. 通过PhD Qualification Exam（PQE/博士资格考试）后 → **PhD Candidate/博士候选人**（助学金/PGS会上涨）
  3. 通过PhD defense/博士答辩后 → **PhD/博士**

#### 1.2 学制

- **正常学制时间（Normative Period of Study）**：一般为四年，已有研究型硕士学位则为三年
- 超过学制无法毕业的处理：
  - 三个月内毕业：可获本学期学费一半退款
  - 只差最后thesis：可转为**continuing student**身份，交较少学费
  - 最长年限：PhD必须**八年内毕业**
- 宿舍优先级：前两年RPG学生priority最高，其次是正常学制时间内学生，最后是学制时间外学生

#### 1.3 费用

| 项目 | 金额 |
|------|------|
| 每年学费 | 42,100港币（春秋季各交一半） |
| PGS助学金（2021/22） | 18,030港币/月，一年发12个月 |
| 宿舍费 | 2,000~4,000+港币/月 |
| HKPFS港府奖学金 | 26,900港币/月（2021-22学年）+ 每年13,500港币开会差旅费 |

> 实际每月可用：PGS 18,030 - 学费平摊3,508 - 宿舍4,420 ≈ 10,102港币

**关于PGS发放**：PGS的发放需要看具体科研表现，老板认为performance太差可以随时停掉下一学年/学期的PGS。

#### 1.4 课题组组成

| 角色 | 说明 |
|------|------|
| **PI（Principal Investigator）** | 课题组负责人，一般只有一个 |
| **RA（Research Assistant）** | 科研助理，本科毕业生积攒经验为申PhD做准备 |
| **Research Associate / PostD** | 博士后，已拿博士学位者为找教职积攒经验 |
| **RAP（Research Assistant Professor）** | 研究助理教授，非tenure-track，理解为更senior的postD |
| **行政staff** | 处理杂活，一般学生和博后分担部分工作 |
| **RPG students** | 科研主力（有学位压力） |
| **MSc/UG students** | 一般做UROP、capstone、Independent Project等 |
| **Visitors** | 访问学者、访问学生 |

> 科大实行tenure-track制度，助理教授（AP）虽有考核期但已有资格作为PI招收PhD和MPhil学生

#### 1.5 组会

**组会（Group Meeting）** 是课题组定期召开的会议，是指导PhD学生成长的最重要的环节。

- **未确定研究方向的新生**：讲文献综述，讲述对行业的理解、研究热点、潜力方向
- **已定方向的学生**：汇报科研进度，如文献复现结果、实验/计算结果等

组会是一个**被judge的过程**——需要用充实的论据、严密的逻辑捍卫观点，说服导师和审稿人。

### 2. 博士申请

#### 2.1 申请手续

- **申请时间**：一般9月~12月投递（申请HKPFS需在12月1日前提交并让导师推荐）
- **重要材料**：RP（研究计划）、推荐信、科研经历及发表文章
- **基本门槛**：本科学校背景、GPA、雅思

**"套磁"（Email Solicitation）**：通过邮件与教授/PI取得联系，让对方熟悉你的科研背景并产生兴趣，是港校博士申请中非常常规的操作。

套磁内容：告诉PI你是一个怎样的人、有怎样的科研背景、对课题组什么方向感兴趣并有什么想法。如果PI对你感兴趣且有funding，会给口头offer。

> 决定导师招生最重要的因素就是**funding**

#### 2.2 科研经历

科研经历是博士申请中很重要的一部分。有科研经历的人更具优势，也更能判断科研是否适合自己。

**积累科研经历的方式：**
- **本科生**：UROP（Undergraduate Research Opportunities Program）、capstone project
- **授课型研究生**：Independent Project
- **直接申请**：给感兴趣的PI发邮件申请做志愿者/RA

> 这是比邮件套磁更加真诚且有效果的方式——导师亲身与你接触，对你的人品和能力有所信任

#### 2.3 MPhil还是PhD？

| 对比项 | MPhil | PhD |
|--------|-------|-----|
| 学制 | 2年 | 3~4年 |
| 延毕 | 一般没有 | 较常见 |
| 名额 | 比PhD少很多 | 相对较多 |

**MPhil适合人群**：
- 还没想好是否要读博的同学——进可攻退可守
- 顺利的话读一年可转PhD，省下时间
- 积攒经验申请更好的大学的PhD
- 不适合科研的话，拿到MPhil学位找工作也没问题

**MPhil申请可能比PhD更激烈的原因**：
1. 名额少
2. PI希望MPhil学生一来就能上手干活
3. 短平快项目直接招full time RA更划算

> 商学院和人文学院：如果没读过MPhil或相应研究生，申请PhD几乎不可能

### 3. 读博建议

科研工作的特点：
- 不是有明确KPI、明确可执行路径的工作
- 需要**专注和耐心**，避免碎片化
- 需要不断**挑战舒适区**
- 需要**注重细节**，不怕dirty work
- 需要**劳逸结合**，合理安排时间

> 实在不行quit PhD也并不丢人，这条路不一定适合所有人

## 官方提醒

博士/MPhil申请要求、奖学金、学费、PGS、最长修读年限和住宿规则会按学院、项目和年份变化。申请或决策前，请查 HKUST FYTGS、目标学院/系、导师主页及官方招生页面。
