# 香港购物与网购转运攻略

> 来源：MSSS 2025年新生攻略14
> 原文链接：https://mp.weixin.qq.com/s?__biz=MzAwNjAxNTYxNw==&mid=2651458259&idx=1&sn=bfc1bed13905fbcc67fba0ef526a92a2

## 一、香港本地购物

### 1.1 官方店铺购买

从官方店铺购买最保险。官网可查旗舰店、零售店地址及价格，部分支持官网下单送货到家（如苹果、宜家等）。

### 1.2 零售店

品牌授权零售店示例：
- **丰泽** — 飞利浦电动牙刷、小米空气净化器、戴尔电脑等
- **莎莎** — 各种品牌美妆产品

### 1.3 格价网站

**香港格价网（HK Price）**：整合实体店和网店，可对比价格后线上或线下购买。

其他平台：**HKTV mall**、**香港消费者委员会**官方格价平台

### 1.4 二手交易平台

- Facebook 各群组
- Carousell 网站
- MSSS 科大二手群

## 二、内地到香港的网购平台

### 2.1 淘宝

淘宝发货到香港有两种方式：

**直运（菜鸟官方直运 / 菜鸟官方直运—快捷）**
- 下单时直接填香港地址，商品费用和运费一起结算
- 所有商品到齐后自动合单运来香港
- 按体积和重量计费，大件家具不划算
- 取件方式：自提点 / 上门派送（自提比上门便宜）
- 「快捷」比普通直运更贵，每个包裹分开计重

**集运（菜鸟官方集运 / 菜鸟官方集运—快捷）**
- 下单时填香港地址，自动生成集运仓地址
- 店家寄到集运仓，只需付商品费用（不含运费）
- 所有商品到齐后点击「前往合单」手动选择并支付运费

**其他选项**
- 满99香港跨境段包邮活动：https://world.taobao.com/wow/oversea/act/hongkong
- 部分商品不支持发货到香港，或集运费用过高，需用转运服务

### 2.2 拼多多

支持官方集运：
1. 选择香港收货地址，选择官方集运
2. 商品到集运仓后，在订单详情中选择去集运
3. 选择收货方式：自提点/自提柜 或 送货上门
4. 支付后查看配送（神州/顺丰/极兔，价格不同）

### 2.3 京东及天猫超市

- 下单时填香港地址，会自动显示运费
- 部分商品满一定金额且重量在范围内可免运费
- 不定期有满XX元包邮促销活动
- 运费说明：https://help.jd.com/user/issue/109-3492.html

### 2.4 顺丰

- 顺丰官网有完整计价方式
- 也可先寄到广东转运仓再转到香港（见第三节转运服务）

## 三、转运服务

### 3.1 转运业务逻辑

当商品无法直接到香港或淘宝/京东集运费用过高时，使用转运：

1. 在转运公司官网/APP/小程序注册，获得一个**内地仓库地址**（一般在广东如东莞、深圳）
2. 网购时填这个内地仓库地址
3. 转运公司把物品从内地仓库运到**香港取货点**
4. 你到香港取货点取货，支付从内地仓库到取货点的费用（按重量/体积计价）

### 3.2 科大同学常用的转运公司

| 公司 | 网址 |
|------|------|
| 漂流瓶 | https://www.piaoliuhk.com/ |
| 4px | https://hk.4px.com/ |
| 淘集运 | https://www.taojiyun.com/ |
| 神州集运 | https://www.szjy188.com/ |

**漂流瓶** 特点：
- 取货当天或提前一天短信通知
- 校内取货点：**LG7停车场**
- 校外取货点：**大埔仔停车场**（离科大北门约步行5分钟）
- 可合并多个包裹一起送，1kg以下统一 **12.5港币** 起

## 四、安全提示

- 与陌生人交易验证身份，交易地点选安全场所（科大校园内）
- 谨防二手交易诈骗
- 大额购物建议走官方渠道
